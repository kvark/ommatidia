# Raw-ReSTIR replacement checkpoint — 2026-08-12

Device: Radeon RX 7900 XT (`0x744c`).

## Training

- Dataset: 2,400 procedural scenes, raw Blade ReSTIR at 128×128 and 256-frame
  canonical references at 256×256; 2,040 training / 360 held out.
- Model: direct objective, base 24, three levels, one block per level, 649,200
  parameters, 104.1 convolution GFLOP per 1080p frame.
- Run: 20,000 steps, batch 8, cosine `3e-4` to `1e-5`.
- Throughput: 38.6 steps/s; 518.1 seconds.
- Loss: 1.157925 to 0.602979.
- Held-out error over 128 crops: nearest 0.005768, network 0.002939,
  **+2.93 dB**.

## Matched Blade baseline

Two new 128-scene captures used seed 10000 and current Blade, differing only
in whether its three-pass variance-guided SVGF filter was enabled. Their
canonical record payloads were byte-identical. The last 19 scenes supplied 76
non-overlapping held-out crops.

- Raw ReSTIR nearest: 0.005748.
- Ommatidium from raw ReSTIR: 0.002876, **+3.01 dB** over raw nearest.
- Blade SVGF plus nearest upscale: 0.004284.
- Ommatidium improves over the filter it replaces by **1.73 dB**.

The Ommatidium checkpoint also scores 0.001501 if stacked after SVGF, but that
is not the deployment configuration and is not used for the replacement claim.

## Runtime

The deployment backbone was re-measured at a 720×720 input / 1440×1440 output,
which is the same 2.07 million output pixels as 1920×1080: **19.4 ms**, or
roughly 52 fps, on an idle RX 7900 XT. This is the 104.1 GFLOP network step;
texture packing, unpacking, and display post-processing are outside that
number. The earlier 34.1 ms result was taken under device contention.

Meganeura's five-sample structured trace accounts for 97.5% of profiled wall
time with GPU timestamps. Its 84 dispatches occupy 73 barrier groups and break
down as follows:

| kernel family | dispatches | time | share |
|---|---:|---:|---:|
| spatial convolution | 45 | 17.29 ms | 86.8% |
| normalization and reduction | 30 | 1.54 ms | 7.7% |
| pointwise | 7 | 0.58 ms | 2.9% |
| data movement | 2 | 0.50 ms | 2.5% |

The largest single dispatch is the scalar `Conv2dGemm` after the full-resolution
decoder concatenation: 4.06 ms, or 20.4% of the timestamped frame. The trace
reports no SGPR or VGPR spills. It also exposes the next bandwidth target:
3.25 GB of logical buffers reduce through aliasing to 1.22 GB of physical
allocations, 603 MB of them device-local.

Timestamp queries did not cause the earlier 1.30-second result: that run had
silently selected the default adapter instead of the discrete GPU. On the RX
7900 XT, the revised median protocol measured 20.24 ms profiled against 20.04
ms uninstrumented, **1.0% instrumentation overhead**. A prior run measured
5.4%, putting the observed cost in the low single digits rather than anywhere
near the wrong-adapter result. The query pool is allocated when the context is
created; per-dispatch timestamps are enabled only for retained samples, and
two ordinary submissions advance Blade's command-buffer ring before results
are read. This avoids a query readback stall in the measured submission.

The structured trace is trustworthy at the family and millisecond-dispatch
level, with two qualifications. Profiling puts every dispatch in its own
compute pass instead of the normal single pass with inline barriers between 73
dependency groups. That adds 83 pass boundaries and separately serialises the
eleven dispatches which normally share a group. Vulkan top-of-pipe timestamp
intervals also include the barrier before the next dispatch. Normal latency
therefore comes from a separate uninstrumented median; the instrumented trace
explains that latency rather than replacing it. The profiling test now requires
an explicit `OMMATIDIA_TEST_DEVICE_ID`, so choosing the wrong default adapter
is an error instead of a plausible-looking result.

The live check used `ommatidia-data --checkpoint runs/raw-restir-b24`: it
rendered raw ReSTIR, borrowed `RayTracer::view_radiance` and `view_gbuffer`,
packed them into Meganeura, ran the trained checkpoint, unpacked its pinned GPU
output into `Rgba16Float`, and read the predicted preview successfully.
